Caso destacado

El Tizón: un sistema para operar un restaurante de verdad.

El Tizón es un sistema administrativo construido alrededor de una operación real de restaurante. No parte de una plantilla genérica: parte de mesas, comandas, venta rápida, venta en línea, producción, cobro, repartos, inventario, usuarios, proveedores, resurtido, cortes e impresión.

Método

Primero entiendo la operación. Después escribo código.

  1. 01Entender el problema y la forma real en que trabaja la gente.
  2. 02Definir qué debe resolver la primera versión sin inflarla de más.
  3. 03Construir una base funcional que se pueda usar, probar y mejorar.
  4. 04Documentar reglas, decisiones, pendientes y rutas de crecimiento.
